# ✅ Kanban Task Manager (MERN Stack)

A modern **Kanban Task Management System** built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js).  
This application helps users manage tasks smoothly using a **drag-and-drop workflow** with secure **JWT Authentication**.

---

## 📌 Project Overview

The **Kanban Task Manager** is designed to improve productivity by organizing tasks into columns such as:

- ✅ **Pending**
- 🔄 **In Progress**
- 🎉 **Completed**

Users can easily drag and drop tasks between different stages to track progress efficiently.

---

## 🚀 Features

✅ **User Authentication (JWT Based)**
- Signup / Login
- Secure Token Storage
- Protected Routes

✅ **Task Management**
- Create tasks
- Move tasks between columns (Drag & Drop)
- Update task status dynamically

✅ **Profile Section**
- View user details
- Secure access through authentication

✅ **Modern UI**
- Glassmorphism design
- Gradient background theme
- Responsive layout (Mobile + Desktop)

✅ **Secure Backend**
- Token verification middleware
- Protected APIs
- Centralized error handling
